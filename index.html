OSPF Overview

OSPF is a Link State Routing Protocol.

It is designed by IEEE and standardized.

RFCnumber is 2328

Cisco Offical Website

LSA is a packet sent by OSPF to share routing information.

We also compare it with EIGRP and BGP

Subnet Calculation

A /24 network gives us 28 = 256 addresses.

A /16 network gives us 216 = 65,536 addresses.

Basic OSPF Commands

To verify OSPF neighbor use <show ip ospf neighbor> command.

Type this command:

show ip rotute ospf

Executed output

Shows the OSPF routing table entries

Full OSPF configuration example:

router ospf 1
network 172.16.0.0 0.0.255.255 area 10
router-id 1.1.1.1

The syntax is: router ospf < process-id>
